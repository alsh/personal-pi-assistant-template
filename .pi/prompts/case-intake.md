Help the user set up a private local document case named "$@".

First list existing cases to avoid duplicates. Ask for or confirm:

- the exact case title and scope;
- due date, if any;
- the user-provided checklist of required documents/tasks;
- which currently indexed documents should be linked.

Create the case/tasks/links only through the confirmation-required case tools.
Do not invent legal or administrative requirements. Do not submit anything,
contact an authority, write to Google Calendar, or imply that a submission has
happened.
